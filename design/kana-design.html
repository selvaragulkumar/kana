Mark states

Set data-state on .kana-mark. Pure CSS; respects reduced motion.

idleStatic. App open, no session.
connectingQuarter-turn steps while the engine starts or reconnects.
listeningSlow breathe. Session live, waiting for speech.
talkingQuick pulse inward. Push-to-talk held.
translatingWhite traces, then red. Output being produced.
errorOne shake, white dims.

Suggested mapping: Start pressed → connecting; IN+OUT open → listening; hotkey held → talking; translated audio playing → translating; engine fatal → error; Stop → idle. Use the same state for the menu bar icon (template version, static) and the panel header mark.
